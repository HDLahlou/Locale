# S4 gate: add four real device photos

**Why a person is needed.** The image tests must prove that real phone photos survive the pipeline unchanged: an HDR gain map, a Live Photo still, an Android Ultra HDR JPEG and an Android HEIC. Agents cannot take photos, so the fixture set has four empty places. Everything script-made is done and verified (`just fixtures-verify` passes).

**What this unblocks.** The device-photo parts of M0a-5 (location strip) and M2-3 (validation pipeline). Until then those tasks run on script-made fixtures only.

**Setup items needed.** Item 2 (the photos) and item 3 (one iPhone on iOS 16 or later, one Android phone on 9 or later).

## Steps

1. Take or pick the four photos listed in `fixtures/device/README.md`, and copy them off the phones without conversion, as that file explains.
2. Put them in `fixtures/device/` under exactly these names: `iphone_hdr.heic`, `iphone_live_still.heic`, `android_ultrahdr.jpg`, `android.heic`.
3. Run `python3 -I scripts/fixtures_verify.py --add-device`. Expected: it prints each file's size and hash and sets `"present": true` for it in `fixtures/manifest.json`.
4. Run `just fixtures-verify`. Expected: `fixtures-verify: ok` with no "waiting for a person" lines.
5. Commit the four photos and the manifest on `build/integration`, then run `docs/agentic/start-build.sh`.

The photos may carry real location data; that is what the strip tests need. Do not use photos you would not want in the repository.
