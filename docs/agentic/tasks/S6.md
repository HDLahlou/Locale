- Cause in `scripts/doctor.py` (S2, ~line 73): `subprocess.run(..., timeout=limit)` kills only the `.cmd` shell on Windows; the grandchild (the sleeping process) keeps the output pipe open, so `run()` blocks until it exits (60 s).
